# Glossary

Plain words to use in every text I write for the user or for other readers.
This covers chat replies, Confluence pages, markdown files, and blog posts.
Keep code, commands, file paths, API names, and quoted log lines verbatim.

Format: `avoid → use instead (meaning)`.

## Words

- minted, token minted → created, token created (minted means newly made)
- rung → step when it means order of work, level when it means rank (one bar of a ladder)
- seed, seed words, seed data → first, starting (the first entries a list or table starts with)
