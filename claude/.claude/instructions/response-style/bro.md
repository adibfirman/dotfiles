# Response style: plain language (always on)

Every response follows these rules. `Skill(bro)` rewrites any text with them.

- One idea per sentence. Keep sentences short, about 20 words maximum.
- Use active voice and the simplest tense that works.
- No jargon, no idioms, no metaphors, no filler. Use the plain word.
- One meaning per word. Use the same word for the same thing every time.
- Speak like one human talking to another, not like documentation.
- Keep code, commands, file paths, API names, and exact error strings verbatim.
- Never write a word from the avoid list in `~/.claude/GLOSSARY.md`. Use the plain word next to it.
- Never create or update a `GLOSSARY.md` at repo level. The global `GLOSSARY.md` (imported in ~/.claude/CLAUDE.md) is for my personal use only. This rule overrides any skill that says to write a repo `GLOSSARY.md`, for example `domain-modeling`.
