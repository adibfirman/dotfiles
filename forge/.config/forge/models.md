# models (forge default)

Model per role, as `- role: model`. `fable`, `opus`, `sonnet`, and `haiku` are
aliases for the latest model of each family. A project file `<main>/.forge/models.md`
overrides single roles. `default` covers any role not listed.

- default: sonnet
- grill-coord: opus
- grill-me-coord: opus
- verify-coord: opus
- exec-coord: opus
- asker: opus
- decider: opus
- planner: opus
- gate-review: opus
- fact-finder: sonnet
- tla-writer: sonnet
- unit: sonnet
- gate-beh: sonnet
- gate-spec: sonnet
- gate-sec: sonnet
- classifier: haiku
- commit: haiku
